 ระบบจองที่นั่ง ม.1/9

เว็บไซต์สำหรับจองที่นั่งในห้องเรียน ม.1/9 โรงเรียนเตรียมอุดมศึกษาพัฒนาการ สุวรรณภูมิ ปีการศึกษา 2569

ผังห้องจำลองตามที่นั่งจริง มี 4 แถว แถวละ 3 โต๊ะ โต๊ะละ 3 ที่นั่ง รวม 36 ที่นั่ง นักเรียนสามารถแตะที่นั่งที่ต้องการ ใส่ชื่อ แล้วกดยืนยันเพื่อจอง หากต้องการยกเลิก ให้แตะที่นั่งของตัวเองอีกครั้ง
